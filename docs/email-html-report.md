# Sending HTML Reports by Email (Office 365 Connector)

## Prerequisite

The **Office 365 Outlook** connector must be configured on the agent with the `SendEmailV2` tool enabled.

## Sending Pattern

When the user asks to send an HTML report by email, the agent MUST follow this workflow:

### Step 1 — Generate the HTML Report

Run the current skill's `generate_html_report.py` script to produce the HTML file:

```bash
python3 codeRefs/sec-sre-ag/<skill-name>/generate_html_report.py \
    <input-dir> \
    --output-dir reports/<skill-name>/ \
    --tenant <tenant_name>
```

The script saves the HTML file in `reports/<skill-name>/` with a name that includes the tenant and timestamp.

### Step 2 — Send the Email with the Attachment

Call the `office365_SendEmailV2` tool with this structure:

```json
{
  "To": "<recipient-email-address>",
  "Subject": "<descriptive subject with tenant and score/result>",
  "Importance": "High",
  "Body": "<p>Brief summary of the results in the email body (HTML).</p>",
  "Attachments": [
    {
      "Name": "<readable-file-name>.html",
      "ContentBytes": "<relative-path-to-generated-html-file>"
    }
  ]
}
```

### CRITICAL Rules for `ContentBytes`

| Rule | Detail |
|------|--------|
| **Type** | Plain string containing the file path in the workspace |
| **Do NOT use** | JSON objects with `$content-type`/`$content`, direct base64 content, or URLs |
| **The tool handles encoding** | The tool reads the file from the supplied path and automatically encodes it as base64 |
| **Size limit** | Maximum 5 MB total for all attachments in a single email |
| **Relative path** | Use paths relative to the workspace root, such as `reports/identity-posture/Report.html` |
| **Send once** | Do NOT repeat the send if the tool returns `isError: false`; the email was sent successfully |

### Concrete Example — Identity Posture

```json
{
  "To": "admin@contoso.onmicrosoft.com",
  "Subject": "🔐 Identity Posture HTML Report — Tenant contoso — Score 45/100 🟡 Elevated",
  "Importance": "High",
  "Body": "<p>The complete <strong>Identity Security Posture</strong> HTML report is attached.</p>",
  "Attachments": [
    {
      "Name": "Identity_Posture_Report_contoso_2026-08-06.html",
      "ContentBytes": "reports/identity-posture/Identity_Posture_Report_contoso_2026-08-06_070404.html"
    }
  ]
}
```

### Common Errors and Solutions

| Error | Cause | Solution |
|-------|-------|----------|
| Empty or corrupted attachment | `ContentBytes` contains direct base64 data or a JSON object | Use the file path as a plain string |
| Duplicate emails | The agent repeats the send because it is unsure about the format | If `isError: false`, the email was sent. Do not repeat it. |
| File not found | The path is incorrect or the file has not been generated | Verify that `generate_html_report.py` ran BEFORE sending the email |
| Attachment larger than 5 MB | The HTML report is too large | HTML reports generated by these scripts are self-contained and typically smaller than 500 KB |
